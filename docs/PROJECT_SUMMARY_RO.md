# Rezumat pentru CV și LinkedIn

**Retail Analytics Platform** — platformă modulară de Business Intelligence și analiză de date pentru retail, construită cu Python, Streamlit, pandas, scikit-learn și Plotly.

Am proiectat un flux analitic complet care include ingestia și maparea semantică a datelor, controlul calității, dashboard-uri executive, RFM și Customer 360, analiza produselor și magazinelor, forecast, guvernanța modelelor, catalog, lineage și extensii prin pluginuri. Am introdus validare runtime, testare automată pe Python 3.10–3.12, build Docker și un dataset sintetic reproductibil cu verificări SHA-256.

**Tehnologii:** Python, Streamlit, pandas, NumPy, scikit-learn, Plotly, pytest, Docker, GitHub Actions.
