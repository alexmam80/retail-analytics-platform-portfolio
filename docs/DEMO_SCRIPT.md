# Five-minute demo script

## 0:00–0:35 — Context

Present Retail Analytics Platform as a modular retail BI and data-science workspace. Explain that the public repository contains no proprietary source code and no real customer data.

## 0:35–1:10 — Data and quality

Load the synthetic demo dataset and show schema mapping, completeness checks, duplicates and controlled quality cases.

## 1:10–2:00 — Executive view

Open the Executive Dashboard. Highlight total revenue, estimated profit, customers, transactions, trends and automated alerts.

## 2:00–2:50 — Customer intelligence

Show RFM segments, Customer 360, monthly evolution, preferred categories and recent transactions.

## 2:50–3:35 — Product, store and forecast

Demonstrate product/store drill-downs and explain forecast/model comparison and anomaly detection.

## 3:35–4:20 — Governance and platform architecture

Show catalog, lineage, quality controls, plugin marketplace, event bus and background jobs.

## 4:20–5:00 — Engineering quality

Finish with the CI matrix for Python 3.10–3.12, Docker build, deterministic demo bundle and runtime validation.
